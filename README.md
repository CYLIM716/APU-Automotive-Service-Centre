# APU Automotive Service Centre

## Project Overview
APU Automotive Service Centre is a Java-based application developed as part of an academic project. It aims to manage automotive service centre operations through a simple system.

## Technologies Used
- Java
- Java Swing
- Object-Oriented Programming (OOP)
- File Handling

## Main Features
- User Login and Role Management
- Manage Staff
- Set Service Prices
- View Customer Feedback
- Generate Income Reports
- Manage Customer Service Records

## User Roles
- Manager
- Counter Staff
- Technician
- Customer
